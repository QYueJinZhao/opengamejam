# ICP 备案 · 信息填报表

> 适用：抖音小游戏《超载快车》· 个人主体（张建乐）· 无版号 IAA
> 入口：抖音开放平台「开发者后台 → 设置 → 基础设置 → ICP 备案」或总览页「ICP 备案 → 完善信息」
> **前置条件：小游戏备案必须先审核通过，否则 ICP 备案入口不开放。**

| 证件号码 | 【填写身份证号】 | 与平台实名认证信息一致 |

| 通讯地址 | 【填写实际居住地址】 | 建议填广州市天河区的现居住地址，精确到门牌号 |
| 主体负责人 | 张建乐 | 个人主体即本人 |

**关键规则**

1. 证件主体必须与小游戏主体信息一致。个人主体下，平台实名认证的姓名、身份证号必须与填写的完全一致。
2. 证件须在有效期内，且剩余有效期不少于 3 个月。
3. 个人主体的「证件注册地址」与「通讯地址」**可以不一致**。平台按通讯地址所在省管局提交核准。
4. 通讯地址填广州，即由**广东省通信管理局**审核；填福州，则由福建省通信管理局审核。两省对个人主体的材料要求不同，选定后不建议中途更改。

## 五、附件材料清单

| 材料 | 规格 | 状态 |
|---|---|---|
| 主体证件 | 身份证正反面，彩色拍照或扫描原件，四角完整、国徽不遮挡、无反光 | 待备 |
| 负责人证件 | 同上（若与主体同一人，通常复用） | 待备 |
| 手持身份证照片 | 部分省管局要求，人脸与证件同框、文字清晰 | 待备（按页面提示） |
| 居住证明 | 部分省管局对非本地户籍要求居住证或社保记录 | 待备（按页面提示） |
| 小程序补充材料 | 仅在营业执照/名称/类目命中前置审批关键词时要求 | 不适用（个人主体） |
| 承诺书 | 按平台模板手写签名 | 待备（按页面提示） |

**证件拍摄要点**

1. 必须拍原件，不能拍复印件、打印件、屏幕截图。
2. 四角完整，边缘不裁切，国徽与签发机关清晰。
3. 背景色调一致，无反光、无阴影遮挡文字。
4. 不加与核准无关的水印；如必须加，仅可加「仅供抖音小游戏ICP备案使用」单行文字，且不遮挡证件信息。
5. 照片方向为正立，不倾斜、不倒置。

## 七、备案号下发后的动作

1. 在「设置 — 基础设置 — 资质信息 — ICP 备案」处查看备案号，格式形如 `粤ICP备XXXXXXXX号-XX`。
2. 核对备案号中的主体名称、小游戏名称是否与平台信息一致，如有错误立即点「修改」重新提交。
3. 按平台要求在小游戏简介或设置页展示备案信息（如平台有要求）。
4. 备案信息发生变更（换手机号、换地址、换主体）时，需在 30 日内办理变更。
