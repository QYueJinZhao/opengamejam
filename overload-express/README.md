# 超载快车 · OVERLOAD EXPRESS

一款面向 **OpenGameJam** 的零依赖纯物理喜剧街机小游戏（纯 ES Module + Canvas2D + 自定义 2D PBD 物理引擎 + Web Audio 程序化音效）。

> **车厢里已经爆满了！** 把胖瘦高矮各异的早高峰乘客叠在车顶、挂在车头车尾与扶手上，随时拍下 **【发车！GO!】**，扛住起步猛冲、铁轨颠簸、低矮涵洞与终点猛刹，看你能活着把多少人运到终点站！

---

## 核心特色

- **静态抢装 → 发车大考两段式博弈**：在站台倒计时结束前自由堆叠，随时手动提前发车（贪心再塞一人还是见好就收？）。
- **多人高速群控**：
  - 点击或**按住左键沿车顶拖动连刷**；
  - 右键 / `Q` / `E` 一键切换 **`×1 单放` / `×3 小队` / `×5 冲锋潮`** 齐扑上车；
  - 发车后按住 **`SPACE`**（或按住画布）指挥**全车人抱头缩身死抓**躲低矮涵洞，按 **`A / D`** 指挥全员压重心。
- **5 种胖瘦高矮物理体型 + 站台限量人池**（杜绝无限刷单一轻体型）：
  - **胖叔（Heavy）**：重宽、超高防滑与抓力，急刹纹丝不动的底座桩；
  - **瘦猴（Slim）**：轻矮填缝不怕涵洞，但单人站车顶易打滑；
  - **竹竿（Tall）**：超长双臂 3 抓点跨堆拉稳，但极怕低矮涵洞；
  - **大包大妈（Bulky）**：侧向偏心大编织袋，专治车厢前后倾斜；
  - **挂壁娃（Climber）**：手脚双端勾挂，专挂车尾爬梯与车头侧沿。
- **零外部依赖 · 中英双语切换**：内置 3 条递进线路（15s / 19s / 22s 黄金单局节奏），支持一键切换 `中文 / EN`。
