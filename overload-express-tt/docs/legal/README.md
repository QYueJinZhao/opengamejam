## 一、一件事分成三段，顺序不能乱

很多人以为「软著 + 备案」是两个动作，实际是四段串行，任何一段没过，后面都开不了口。

```
① 软著登记               ② 平台资质审核           ③ 小游戏备案           ④ ICP 备案
   中国版权保护中心    →    抖音开放平台        →    平台代为申报      →    省通信管理局
   20–60 个工作日          1–3 个工作日             审核通过后开放入口      1–20 个工作日
```

**关键卡点**：无版号小游戏的 ICP 备案入口，只在小游戏备案审核通过后才出现。在小游戏备案通过前，后台看不到 ICP 填写页，这是正常的。

## 五、一条必须说清楚的条款

2026 年 3 月 15 日起，软著申请签章页要求申请人亲笔抄写：

> 本软件确系独立开发，未使用 AI 开发编写代码、撰写文档或生成登记申请材料

本项目的开发过程中有人工智能参与编码与文档整理。这条承诺是否成立、以什么口径申报，是你要做的判断，不是我能在文档里替你解决的技术问题。

我的建议是：提交前向版权中心或正规代理确认 AI 辅助开发的申报口径；口径不明确时，宁可在代码经过你实质性重构与自主消化后再申报，也不要照抄一句不成立的承诺。虚假陈述会记入诚信档案，代价比晚拿证几个月大得多。

## 六、项目侧的两个既有问题（与本次材料无关，但会影响提审）

**1. 单元测试 5 项失败。** `npm test` 当前为 42 通过 / 5 失败。我用还原对比法确认过：把我的改动全部撤掉后仍是同样的 5 项失败，说明是源码在 11-23 凌晨至中午被改动后测试基线没跟上，不是本次改动引入。失败项集中在弹窗热区、镜头缩放、挂壁娃高亮与生产包模拟广告检查。

**2. 自动化截图脚本失效。** `tests/browser_qa.py` 在「适龄弹窗不穿透」一步中断，原因同上——界面改了，脚本里的坐标与文案断言没同步。这也是为什么 `qa/` 下的旧截图不能用于备案：它们生成于 05:02，之后界面又改过（开始按钮从「开始挤车」变为「开始」，顶栏精简，健康忠告补了标题）。

这两点不影响你现在提交软著（软著只看代码与文档），但会影响提审前的自查能力。建议在正式提审前把这些测试修好，否则后续每次改版都要靠肉眼验收。

## 八、后面还会改版，现在能做什么

结论：**软著现在就能办，办完照改不误；ICP 备案现在办不了，不是不想办，是入口没开。**

### 8.1 软著：改版完全不影响

| 担忧 | 实际情况 |
|---|---|
| 改代码后证书对不上 | 软著登记的是提交那一刻的代码表达。后续迭代产生新表达，原证书继续保护原表达，两者不冲突 |
| 平台会不会比对代码 | 不会。抖音只核验证书存在、名称匹配，不读代码 |
| 说明书里的截图会过期 | 本套说明书是**纯文字的**，不含任何截图，改版不会让它失效 |
| 源程序 PDF 只有 60 页 | 规范就是前 30 + 后 30，本来就不提交全量代码，改动不影响形式合规 |
| 大改之后怎么办 | 调数值、加关卡不用管；重构核心算法建议另做 V2.0 登记 |

登记版本与代码的对应关系已用 SHA-256 固定，见 `软著/04-登记版本代码指纹.md`。改完代码重跑 `python tools/gen_code_fingerprint.py` 就能刷新。

### 8.2 截图：只在两个地方出现

| 用途 | 是否需要截图 | 改版影响 |
|---|---|---|
| 软著登记 | **不需要** | 无 |
| 小游戏备案 | 需要 4 张玩法 + 3 张合规 | 只需提交一次，对应「首次提审通过的那一版」 |
| ICP 备案 | **不需要**玩法截图，只要证件照 | 无 |

所以「截图还会变」这件事，只影响小游戏备案那一次提交。备案完成后的版本迭代不需要重新备案（除非改名、换主体、改服务内容或加内购）。

### 8.3 唯一需要现在定死的东西

这些一旦写进证书和备案表，改动成本很高：

| 项目 | 当前取值 | 能否改 |
|---|---|---|
| 软件全称 | 超载快车游戏软件 | 改名要变更登记，150 元 + 重审 |
| 游戏名称 | 超载快车 | 同上，且平台侧要改基本信息 |
| 著作权人 / 主体 | 张建乐（个人） | 换企业主体要变更登记 + 重新备案 |
| 版本号 | V1.0 | 后续可做 V2.0，不用改 V1.0 |
| 服务内容类目 | 游戏 / 休闲游戏 | 改成别的类目要变更备案 |
| 盈利模式 | 广告盈利（无内购） | 加内购需企业主体 + 版号 + 重新备案 |

**只要这六项不动，代码和界面怎么迭代都不影响已办的资质。** 反过来说，如果你打算后期加内购或者换公司主体，那现在就该先定下来，别等备案做完再改。

### 8.4 建议的推进节奏

```
现在          → 提交软著（材料已齐，改版不影响）
软著受理后    → 平台主体认证 + 创建小游戏 + 传软著与自审报告
版本稳定后    → 截 7 张图，提审首个版本
提审通过后    → 小游戏备案自动申报
小游戏备案过  → 填 ICP 备案
之后随便改    → 只要不改名、不换主体、不加内购，不用重备
```

关键判断：**不要为了等「最终版」而拖软著**。软著审查 20–60 个工作日，是整个链条里最慢的一环，越早提交越好。等你改完再交，等于把两个月白白推后。
