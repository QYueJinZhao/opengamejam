## 一、截图规格

| 项目 | 要求 |

| 分辨率 | 长边不低于 1080 px，横屏截图建议 1920 × 1080 或按设备实际分辨率 |

## 五、为什么没有复用 qa 目录里的旧截图

`qa/20261123-plan-followup/` 下的截图生成于 11-23 05:02，而 `src/render.js`、`src/ui_canvas.js` 在之后仍有改动（当前为 12:2x）。两者不一致：

- 旧截图的开始按钮文案为「开始挤车」，当前为「开始」
- 旧截图顶栏含「第 1 站 · 早高峰首发」下拉、车库与侧边栏入口，当前顶栏已精简
- 旧截图底部健康忠告**没有标题**，当前已补「《健康游戏忠告》」

用旧截图提交会被认定为「截图与版本不一致」，属于常见拒审原因。因此本目录只保留按当前源码重新截取的开屏图，其余一律重截。

## 六、截取操作路径

### 路径 A：抖音开发者工具（推荐，接近真机）

1. 打开字节跳动开发者工具，导入 `dist/` 目录（先执行 `npm run build:production`）。
2. 选择横屏机型模拟器（建议 iPhone 12 或 1920 × 1080 安卓机型）。
3. 进入游戏，按第二节四张图的取景要点操作并截图。
4. 开发者工具的截图功能在模拟器工具栏，导出为 PNG。

### 路径 B：抖音 App 真机（防沉迷与实名必须用这条）

1. 用开发者工具「预览」生成二维码。
2. 分别用未实名账号与未成年账号扫码进入。
3. 在弹窗出现时用系统截屏。
4. 截图后裁掉状态栏中的个人信息（如手机号、通知内容）。

### 路径 C：本地浏览器（仅用于自查，不建议提交）

```bash
npm run build:production
PORT=8899 node serve.mjs --no-open
# 浏览器打开 http://127.0.0.1:8899/
```

当前 `tests/browser_qa.py` 与最新界面不同步（适龄弹窗热区检查失败），自动化截图不可用，需手动操作。
