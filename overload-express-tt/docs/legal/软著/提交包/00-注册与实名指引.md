# 注册与实名认证指引（必须先做完这一步）

> 这一步只能你本人做：需要手机验证码、身份证照片、手持证件照。
> 采用「你操作、我陪跑」模式：你做到哪一步卡住，就把页面提示或截图发我，我逐条告诉你怎么处理。
> 预计耗时：注册 5 分钟，实名材料准备 10 分钟，官方审核 1–3 个工作日。

---

## 一、注册（4 步，5 分钟）

**入口**：官网 `www.ccopyright.com.cn` 右上角「注册」，或直接打开 `register.ccopyright.com.cn/login.html`

| 步骤 | 操作 | 注意 |
|---|---|---|
| 1 | 阅读用户协议 → 点「同意并继续」 | — |
| 2 | 选择身份：**个人** | 选「机构」会走营业执照核验，你是个人，别选错 |
| 3 | 创建账户：用户名、手机号、验证码、密码、确认密码 | 手机号必须**本人实名**，且与身份证持有人一致 |
| 4 | 点「下一步」，看到「恭喜您注册成功」 | 把用户名、密码记在安全的地方 |

**三个硬规则**

1. 手机号必须是本人实名认证的号码，且**一个手机号只能认证一个著作权人**，不能重复用于注册他人。
2. 用户名建议用手机号或常用邮箱，方便记忆。
3. 注册后系统会要求完善邮箱并做邮箱验证码校验，提前准备好常用邮箱。

---

## 二、实名认证（这一步是卡点）

注册完点「版权登记」→ 随便选一个业务（如 R11）→ 会弹出「您还未实名认证，请先实名认证再操作」→ 点「前往实名认证」。

### 2.1 要传三样东西

| 材料 | 要求 |
|---|---|
| 身份证正面照 | jpg / png / jpeg |
| 身份证反面照 | jpg / png / jpeg |
| **手持身份证正面照片** | jpg / png / jpeg，人脸与证件同框，证件文字清晰 |

第三项是最容易失败的一项。很多人以为只要正反面，结果卡在这里。

### 2.2 手持照怎么拍

| 要点 | 说明 |
|---|---|
| 同框 | 人脸和身份证正面必须在同一张照片里，不能只拍证件 |
| 清晰 | 证件上的姓名、号码、有效期要能看清，不能糊 |
| 光线 | 均匀自然光，不要逆光，不要开闪光灯直打 |
| 无反光 | 证件表面不能有反光斑，否则文字识别失败 |
| 不遮挡 | 手指不要挡住证件信息区，口罩帽子墨镜全部摘掉 |
| 不修图 | 不要美颜、不要裁剪、不要加滤镜 |
| 方向 | 正立，不要横拍后不旋转 |

**水印**：如确需加水印，官方允许加注「仅供办理中国版权保护中心各项申请使用」，且不得遮挡证件信息。不加最省事。

### 2.3 其他要求

- 身份证剩余有效期不少于 **3 个月**
- 证件信息、手机号实名信息、人脸三者必须一致
- 提交后等 **1–3 个工作日**审核，可在「账户管理」查看结果

---

## 三、常见失败原因（照着排）

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示信息不匹配 | 注册手机号不是本人实名，或姓名有错字 | 换本人实名手机号重新注册 |
| 证件识别失败 | 反光、模糊、缺角、拍屏幕 | 重拍，自然光、平铺、四角完整 |
| 手持照被退 | 只有证件没有人脸，或人脸与证件不同框 | 按 2.2 重拍 |
| 一直审核中 | 高峰期排队 | 等，别重复提交；连续失败别频繁换设备 |
| 提示证件有效期不足 | 身份证快到期 | 换新证后再认证 |

## 四、审核通过后

在「用户中心 → 账户管理 → 实名认证」看到审核通过，就可以填表了。

**这时候告诉我一声**，进入填表陪跑：

我先把 `04-填表字段速查.md` 的第 1 项字段值发给你，你填一个、把页面发我确认一个，逐项推进：

1. 进入「版权登记 → R11 计算机软件著作权登记申请 → 立即登记」
2. 按 `04-填表字段速查.md` 逐项填字段，我给你每项的准确取值
3. 粘贴 `03-功能描述-可直接粘贴.txt` 全文
4. 上传 `01-源程序鉴别材料.pdf` 与 `02-软件说明书.pdf`
5. 核对名称、版本号、日期三处一致性
6. **停在上传签章页之前**，交回给你

你独立做的事（涉及本人身份与法律行为，我不能代）：

- 上传身份证正反面（我不经手证件影像）
- 打印签章页 → 手抄承诺 → 签名 → 扫描上传
- 点「提交」

## 五、一个不确定项，先说明

官方 FAQ 里写着「提交申请后，请您按要求打印申请材料及自行准备其他相关材料，**邮寄或现场递交材料**」。这可能是旧流程的残留说明，也可能实际仍要求邮寄纸质件。

2026 年新规口径是全面电子化，但系统里如果弹出邮寄提示，按提示办：把两个 PDF 黑白打印、A4 单面、左侧留装订线，邮寄到北京市丰台区汽车博物馆西路 9 号院 6 号楼 4 层软件著作权部（邮编 100070）。

**提交时留意页面提示**，有邮寄要求就保留快递单号。
