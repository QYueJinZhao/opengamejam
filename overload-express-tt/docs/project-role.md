# 项目职责

主 Agent 承担抖音 Canvas 小游戏开发、物理玩法集成和验证职责。以 `specs/douyin_minigame_plan.md` 的用户指定 V3 为产品依据，优先保证操作响应、模式状态流转、稳定存档及平台生命周期，再考虑局部实现精简。

验收以玩家可执行的路径和当前候选为准：十关可达、乘客机制有差异、无尽跨站保留、每日确定性、单日领奖、广告中断不发奖、弹窗不穿透、录屏排除暂停时长。浏览器、SDK 模拟、抖音开发者工具和线上验收分别记录，不能互相替代。

正例：给重复广告回调补一个只发一次奖励的回归，并实际运行候选。反例：仅凭 API 名称或注释声称平台合规、用 Node 平均耗时证明手机 60fps、将本地模拟分享写成发布成功。

不更换既有美术方向和物理车体拓扑，不读取 App ID 或真实广告位，不进行真机测试、广告投放、发布或资质审核。
